# 생성 콘텐츠 피드백 반영 — 2026-10-26

## 변경 기준

- 제목: 쉽고 구체적인 명사형. 문서 자체의 ‘자료 이용 안내’ 대신 실제로 배우는 내용을 제시한다. 과장이나 원문에 없는 효용은 덧붙이지 않는다.
- 본문: 초·중·고급 모두 ‘-합니다/-입니다’ 설명체. 첫 문장에서 핵심 정보를 전달한다.
- 사실 추출: 문의 담당자·연락처·첨부 안내·게시물의 저작권 이용 안내를 학습 사실에서 제외한다. 저작권 자체가 학습 주제인 경우의 제도 설명은 보존한다.
- 실용 안내: 독자가 활용할 대상·조건·혜택·절차가 남아야 한다. 안내 문구를 뺀 뒤 사실이 3개 미만이면 기존 facts_insufficient로 중단한다.
- 해명 자료: 언론이 제기한 주장을 확인된 사실로 바꾸지 않는다. 반박·불확실성·확정 여부를 보존한다.
- 퀴즈: 숫자 암기보다 핵심 원리·조건·관계 이해를 우선한다. 본문에 없는 목적이나 인과관계를 만들어 묻지 않는다.

## 글 종류와 정답 위치

적합성 결과의 content_kind에 ARTICLE(정보글), GUIDE(실용 안내), NOTICE(자료·게시 안내)를 기록하고 난이도별 생성 결과에도 복사한다. 이는 기존 6개 주제 카테고리와 별개다. 기존 5개 적합성 거부 기준은 유지한다. 앱에서 선택 전에 표시하는 UI와 기존 CSV 컬럼 변경은 이번 작업에 포함하지 않았다.

퀴즈를 저장하기 전에 정답 위치를 무작위 순서의 1·2·3 묶음으로 배정하고, 보기와 answerNo를 함께 변경한다. 동일 실행기의 정상 처리 퀴즈 3개마다 각 위치가 한 번씩 배정된다. 병렬 처리는 잠금으로 보호한다. 기존 DB의 퀴즈와 과거 실행 전체의 비율을 소급 변경하지 않는다. 저장 실패 시 실제 저장 결과의 정확한 균등 비율은 보장하지 않는다.

## 검증 범위

외부 API 호출 없이 21개 자동 테스트 통과. 87개 퀴즈의 병렬 재배치에서 각 정답 위치 29개 및 정답 텍스트 보존을 검사했다. 프롬프트의 실제 출력 품질은 재생성 샘플 검수가 필요하다. 기존 87개 생성글·퀴즈는 변경하지 않았다.
